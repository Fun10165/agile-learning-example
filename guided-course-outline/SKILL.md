# 专家课程目录

为指定主题设计一份可由 [guided-concept-learning](../guided-concept-learning/SKILL.md) 逐节展开的课程目录。外部输出保持教科书目录的简洁；课程深度、范围、依赖和实践能力在内部完成设计与检查。

## 与主 Skill 的分工

- 本 Skill 决定学什么、先后顺序及章节边界；guided-concept-learning 负责每节的动机、精确定义、推导、实例、适用边界和覆盖检查。
- 首次设计时读取主 Skill，确认每节都适合其讲解方式。目录生成阶段不执行主 Skill 的讲解流程，不输出它的覆盖检查，也不创建学习仓库。
- 后续用户要求展开某节时，读取主 Skill，结合完整目录和实际学习进度讲解该节；只使用先前已学或明确已知的前置知识。涉及练习、证明、实验、项目或文献研读的节，要实际开展对应学习活动，不能一律改成概念介绍。
- 本 Skill 只新增或修订目录，不因生成目录而修改主 Skill。

## 确定课程边界

从用户请求和已有材料确定主题、学习起点、目标领域和范围。默认学习者未学过目标学科；把所需的专门前置知识编入课程，明确给出的已有能力可以略去。

用户未给出主题且上下文不能确定时，只询问主题。只有范围歧义会显著改变整门课程时才补问关键问题；其余用合理默认值继续。不要进行背景访谈。

把“专家”落实为在选定范围内能够独立建模、严谨论证、处理陌生问题、比较和选择方法、诊断失败、阅读专业资料并完成综合工作。根据学科调整这些能力，不把所有学科都套成编程项目或数学证明课。目录应提供通向这些能力的完整训练路径，不能把读完讲解等同于已经获得专家资历。

宽泛学科应有共同基础和充分展开的专业分支；狭窄主题应深入其真实边界，不靠堆砌无关分支制造规模。用户有篇幅或课时限制时，优先明确并收窄课程范围，不能删掉核心训练后仍将其标成完整专家课程。

## 内部设计流程

1. **建立领域结构。** 从核心对象、基本问题、理论基础、主要方法和真实工作出发规划覆盖范围。用户资料用于核对范围与术语；若目标是完整课程，不把入门资料的遗漏当成课程边界。对于不熟悉、专业性强或快速变化的领域，查阅权威教材目录、官方标准、专业课程或原始论文校准；不虚构前沿议题或参考资料。遵守环境的检索与引用规则。
2. **倒推能力所需内容。** 从专家需要完成的工作倒推基础和进阶内容。按学科需要覆盖定义与形式表达、核心结论及其推导或证据、方法的操作过程、条件和边界、反例与失败分析、方法比较、综合应用、专业资料研读。不要用“高级专题”“前沿探索”几个空泛标题代替这些内容。
3. **安排先后依赖。** 将必要前置知识排在使用它的节之前，再从基本对象和方法递进到复杂情形、综合判断及独立工作。遇到互相依赖的主题，先建立可用的基础版本，后面再明确深化内容，避免循环前置。目录顺序就是默认学习顺序。
4. **划分章与节。** 一章围绕一个连贯的知识领域或问题族；一节围绕一个能充分展开的明确主题。节名应具体到让主 Skill 知道讲解对象与深度，避免一节装入整门子学科，也避免把每个微小术语拆成一节。章数和节数由内容决定，不套固定数量，不为显得简短而省掉进阶内容。
5. **把训练编进目录。** 在相关理论之后安排具体的推导、证明、问题求解、实验、实现、案例诊断或作品评析，并逐步过渡到开放问题、独立综合任务和专业文献研读。用节名表达训练对象，例如“等价关系与商集的证明练习”，而不是另外附一列学习目标或练习说明。训练应分布在课程中，不能只在末尾补一个笼统的“大作业”。
6. **静默检查并修订。** 检查下面的质量条件，修好后直接交付目录，不展示设计过程。

## 质量条件

- **完整性：** 核心领域和必要专业分支得到实质覆盖；进阶部分不只是末章罗列名词。
- **深度：** 主 Skill 依标题展开后能进入学科需要的形式化、机制、推导、证据、判断与边界，而不止用途和直觉。
- **依赖：** 没有需要先掌握后面章节才能学当前节的隐蔽跳跃。
- **可展开性：** 每节标题及其所在章节足以确定主要内容，无需依赖一份未交付的隐藏说明才能理解。
- **训练：** 存在需要学习者独立完成的活动，覆盖基础熟练度、陌生问题迁移与综合工作；不能把“看懂示例”当成能力验证。
- **专业判断：** 有针对具体对象的假设检查、方法比较、失败诊断和复杂情形，不能只教标准答案。
- **范围一致：** 起点与终点之间的桥梁齐全，既不遗漏基础，也不无限扩张到所有相邻学科。
- **无重复填充：** 重访主题时标题体现新问题或新深度；删去换名重复和没有实质内容的装饰性章节。

## 输出契约

默认只输出课程名、依次编号的章名和节名，使用用户语言：

```markdown
# 课程名称

## 第一章 章名
1.1 节名
1.2 节名

## 第二章 章名
2.1 节名
2.2 节名
```

- 只保留章、节两级，不增加节下知识点、摘要、动机、先修说明、学习目标、时长、难度、验收表、学习建议、总结或可见审计。
- 顺序通过编号表达，不为每节重复“先学”“然后学”。标题简洁但具体，避免“基础知识”“深入理解”“综合应用”等没有对象的名称。
- 实践、研究和综合训练也以普通章名或节名呈现，不另附任务说明。
- 用户要求修改顺序、增删主题或调整起点时，同步修复受影响的前置依赖与编号，默认返回完整的新目录。
- 若检索工具要求标注来源，以最少的行内引用附在相关标题处，保留目录形态；不要另加综述或参考书导读。
- 未被要求时不展开正文、不生成课程网站、不引入学习进度系统。用户指定保存文件时保存，否则直接在对话中提供目录。
